# IsoRim Waylith - Custom Quest Framework Pack

[Custom Quest Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=2978572782) maps with [IsoRimZ](https://steamcommunity.com/sharedfiles/filedetails/?id=3824503834) floors (RimWorld 1.7).

- A CQF map saved on a map with floors keeps them: walls, floors, roofs, stairs and everything upstairs
- Its quest site comes out as it was made, in any game, whatever that game's floor count
- Colonists walk in by the enter spot and up the stairs; enemies upstairs come down
- Reopening a saved map in the CQF editor keeps its floors
- Maps saved without floors behave as they do without this pack

A map with floors can only be a quest site or a main map. As a pocket map, map part, settlement, outpost or scenario start it is refused with a short warning.

Requires IsoRimZ and Custom Quest Framework. Load after them.

让 [Custom Quest Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=2978572782) 的地图用上 [IsoRimZ](https://steamcommunity.com/sharedfiles/filedetails/?id=3824503834) 的楼层（RimWorld 1.7）。

- 在有楼层的地图上保存的 CQF 地图会保留楼层：墙、楼板、屋顶、楼梯和楼上的一切
- 任务地点按原样生成，不受当前存档楼层数影响
- 小人从进入点进来、走楼梯上楼，楼上的敌人也会下楼
- 在 CQF 编辑器里重新打开已保存的地图，楼层不丢
- 没有楼层的地图和不装本包时完全一样

有楼层的地图只能用作任务地点或主地图。用作子地图、地图片段、据点、前哨或开局地图时会被拒绝，并给出简短警告。

需要 IsoRimZ 和 Custom Quest Framework。请放在它们之后加载。
